Security hold email

This is the email the "Email hold link" button sends. You can use these placeholders and they'll be filled in for each guest: [FIRST_NAME], [NAME], [CHECKIN], [CHECKOUT], [AMOUNT], [LINK]. The [LINK] is added automatically at the end if you leave it out.

Check-in instructions

These feed both the guest page and the check-in emails. One line per bullet point. Use [CODE] wherever the lockbox code should appear — the real code is only ever shown in emails and links sent to guests.
